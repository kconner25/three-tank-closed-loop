The process

Three identical tanks in series. Liquid enters tank 1, drains by gravity into tank 2, then into tank 3, then out. The level in tank 3 is controlled by adjusting the inflow to tank 1 with a proportional controller. The sensor reads tank 3's level back with gain 1.

One tank, linearised

A tank drains by gravity, so outflow grows with the square root of level (Torricelli): qout = k·√h. That is nonlinear, so the transfer function comes from linearising about the steady state (hs, qs). The slope there is dq/dh = qs / (2hs), and its reciprocal is the resistance:

R = dh/dq = 2·hs / qs   ·   τ = A·R

The level balance A·dh/dt = qin − qout, with qout = h/R in deviation variables, Laplace-transforms to a first-order lag:

Gtank(s) = H(s) / Qin(s) = R / (τ·s + 1)

Default case: hs = 1.0 m, qs = 0.20 m³/min, A = 1.0 m², so R = 10 min/m² and τ = 10 min per tank.

Block diagram algebra — the rules

Three rules reduce any block diagram. They are the whole method; everything below is just applying them in order.

RuleWhat it saysFormula
SeriesBlocks in a line multiply.G = G₁·G₂·G₃
ParallelBlocks side by side add.G = G₁ + G₂
FeedbackA loop with forward path G and feedback H collapses to one block.G / (1 + G·H)

The feedback sign matters: the formula above is for negative feedback (the measured level is subtracted from the setpoint). With positive feedback the denominator would be 1 − G·H.

Worked example — this process, step by step

Step 1 — the plant (series rule). Each tank is R/(τs + 1), but only the first carries the gain R: tank 2's input is tank 1's level, and a level divided by R is a flow, so H₂/H₁ = 1/(τs + 1), and likewise H₃/H₂ = 1/(τs + 1).

Gp(s) = [R / (τs + 1)] · [1 / (τs + 1)] · [1 / (τs + 1)] = R / (τs + 1)³

Step 2 — the forward path. The controller Gc = Kc sits in series with the plant:

G(s) = Gc·Gp = Kc·R / (τs + 1)³

Step 3 — close the loop (feedback rule). The sensor gain is H = 1, so:

H₃(s) / Sp(s) = G / (1 + G) = Kc·R / [(τs + 1)³ + Kc·R]

Step 4 — put the default numbers in. Kc·R = 0.20 × 10 = 2.0 and τ = 10 min:

H₃(s) / Sp(s) = 2.0 / [(10s + 1)³ + 2.0] = 2.0 / (1000s³ + 300s² + 30s + 3.0)

Step 5 — read the answer off it. Set s = 0 for the steady state: the DC gain is 2.0 / 3.0 = 0.667. A +0.20 m setpoint step therefore settles at +0.133 m, leaving an offset of 0.067 m. That offset is not a mistake in the arithmetic — it is what proportional-only control does: at the new steady state the controller output must be higher than before (the outflow is higher), and with P-only control a higher output needs a permanent error to sustain it.

Stability — where the loop breaks

The poles are the roots of the characteristic equation (τs + 1)³ + Kc·R = 0. They come out in closed form: with a = (Kc·R)1/3, they are (−1 − a)/τ and (−1 + a/2 ± i·a√3/2)/τ. The complex pair crosses the imaginary axis when a = 2, i.e. Kc·R = 8. Routh–Hurwitz says the same thing: for τ³s³ + 3τ²s² + 3τs + (1 + Kc·R), stability needs (3τ²)(3τ) > τ³(1 + Kc·R), which is Kc·R < 8.

Ku = 8 / R   ·   Pu = 2π·τ / √3

Default case: Ku = 0.80 (m³/min)/m and Pu = 36.3 min. At Kc = 0.20 the loop is well inside the limit (Kc·R = 2), yet the response still overshoots by about 30% — three lags in series are enough to make even a stable P-only loop oscillatory. Raise Kc and the offset shrinks while the overshoot grows; the gain study on the App tab shows the trade directly.

Disturbances

A disturbance D — extra inflow to tank 1 — sees the same denominator, with a different numerator:

H₃(s) / D(s) = R / [(τs + 1)³ + Kc·R]

Its steady-state effect is R/(1 + Kc·R) per unit of disturbance flow. At the defaults that is 10/3 = 3.33 m per m³/min, so a +0.01 m³/min disturbance moves tank 3 by +0.033 m in the end. Raising Kc suppresses disturbances and setpoint offset together — the same (1 + Kc·R) does both jobs.

Assumptions and limits

This is a teaching model. The square-root drainage law is linearised about one steady state, so the answers are exact only for small moves around it — a large step, or a level near empty, breaks the approximation. All three tanks are taken as identical; real tanks differ, and their resistances would differ with them. The sensor is ideal (gain 1, no lag, no noise), the valve is ideal (inflow follows the controller output exactly, no saturation), and there is no dead time anywhere in the loop. Adding any of those — valve limits especially — changes the response the site shows.
